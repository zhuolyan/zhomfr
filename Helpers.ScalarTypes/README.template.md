# Helpers for Scalar Types

[![NuGet Status](https://img.shields.io/nuget/v/Zhomfr.Helpers.ScalarTypes.svg)](https://www.nuget.org/packages/Zhomfr.Helpers.ScalarTypes/)
[![NuGet Downloads](https://img.shields.io/nuget/dt/Zhomfr.Helpers.ScalarTypes.svg)](https://www.nuget.org/packages/Zhomfr.Helpers.ScalarTypes/)

A collection of convenient and productive extension methods for some types in C# (`string`, `decimal`, `IEnumerable`),
designed to simplify everyday data processing and formatting tasks.

## 📦 Installation

Install package:

```shell
dotnet add package Zhomfr.Helpers.ScalarTypes
```

After add namespace in using section:

```csharp
using Zhomfr.Helpers.ScalarTypes;
using Zhomfr.Helpers.ScalarTypes.Strings;
```
